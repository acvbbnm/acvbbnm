# Profile assets

## Current technology rows

`skills/*.png` are transparent rows used by the GitHub profile and Notion portfolio. `skills/skills.json` lists their labels and source icon identifiers. Rows use [Shields.io](https://shields.io/) flat-square badges and [Skill Icons](https://github.com/tandpfun/skill-icons), retrieved on 2026-11-18. The purple badge palette and centered category layout reference [narinaresh's profile](https://github.com/narinaresh/narinaresh); biography, experience and project descriptions are original to this portfolio.

The rows show technologies used in projects, coursework and labs, without proficiency scores. Talend is listed as a tool without assuming a particular Talend product or ETL experience.
